Appearance

Theme

Match the system, or choose a fixed theme.

Accent color

Used for the Lantern glow, focus rings, and primary actions.

Tab strip position

Tabs run across the top by default. Turn on Tidemarks to use a vertical rail on the left edge.

UI font size

Halcyon uses 13px by default, slightly larger than other browsers.

Use system title bar

On macOS and Windows, the system title bar takes up the top of the window. Turn this off to use Halcyon's slim frame.

Search

Default search engine

Used when you type a search in the omnibox or on the Plume.

Show search suggestions

Suggestions are sent to your default search engine as you type. Turn off if you'd rather not.

Open search results in a new tab

Clicking a search result opens it in a new tab, leaving the results page in place.

Quiet Mode

Quiet Mode mutes notifications, popups, and autoplay across all tabs. It's on by default. You can toggle it any time with ⌘ShiftM.

Quiet Mode

Mutes notifications, popups, and autoplay across all tabs.

Suppress permission prompts

Sites asking for location, camera, or microphone are queued and shown in the Lantern instead of interrupting you.

Mute autoplay audio

Videos that would autoplay are loaded but muted. You can unmute the tab.

The Lantern

The Lantern is a small indicator in the toolbar. It glows softly when the current site is doing something you might want to know about. It never alerts — it informs on demand.

Show the Lantern

Turn off to remove the Lantern entirely. Most users will want this on.

Watch third-party cookies

The Lantern lights up when a site sets a cookie on a third-party domain.

Watch persistent storage

The Lantern lights up when a site uses LocalStorage, IndexedDB, or the Cache API beyond 5 MiB.

Watch fingerprinting APIs

The Lantern lights up when a site reads Canvas, WebGL, or AudioContext fingerprints.

Tidemarks

Tidemarks shows your tabs as a vertical rail on the left edge of the window. Inactive tabs visually recede. Toggle with ⌘ShiftL.

Show Tidemarks

If on, tabs appear in a left rail instead of across the top.

Rail width

How wide the Tidemarks rail is when not hovered.

Recede inactive tabs

Tabs you haven't looked at in a while fade to lower opacity until you focus them.

Tides

Your browsing history is shown as Tides — a river of pages grouped by day, with weight proportional to time spent. Open Tides

Save Tides

If off, no pages are saved to your Tides. The Cove always doesn't.

Auto-wash after

Pages older than this are automatically removed from your Tides.

Wash all Tides

Remove every page from your Tides. This can't be undone.

Cairn

Bookmarks in Halcyon live in cairns — named stacks you can build and arrange. The default bookmark action adds to your current cairn. Open Cairn

Default cairn

Where new bookmarks land when you don't pick a cairn.

Show cairn icon in toolbar

A small cairn icon next to the Lantern that opens your stacks.

Quill

Quill is a small note-taking surface for jotting things from the page you're reading. Open it on any page with ⌘ShiftN.

Enable Quill

Turn off to disable the Quill shortcut and side panel.

Notes location

Quill notes are per-origin. Choose where they live.

Downloads

Download location

Where downloaded files are saved.

Ask where to save each file

A small dialog before each download. Off by default; turn on if you prefer.

Show download bubble

A small indicator in the toolbar when a download finishes.

The Cove

The Cove is Halcyon's private browsing mode. Pages you open in the Cove don't go to your Tides, don't leave cookies, and don't keep downloads. Your existing bookmarks and settings still work.

Block third-party cookies in the Cove

On by default. The Cove is for private browsing.

Allow extensions in the Cove

Off by default. Most extensions don't belong in private windows.

Anchored tabs

Anchored tabs stay open across sessions. Useful for web apps you always keep open — mail, calendar, music. Right-click any tab to anchor it.

Auto-restore anchored tabs on launch

When Halcyon opens, anchored tabs are restored. Other tabs aren't.

Anchor group position

Where anchored tabs appear in the tab strip.

Languages

Display language

Halcyon's interface language. Restart to fully apply.

Offer to translate pages

When a page is in a language you don't read, offer to translate.

System

Continue running in the background when closed

Lets notifications and downloads keep working after the window is closed. Off by default.

Use hardware acceleration when available

Recommended on for most users. Turn off if you see rendering glitches.
